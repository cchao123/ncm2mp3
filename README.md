# 网易云音乐下载器

一个 macOS / Windows 桌面应用：扫码登录网易云音乐账号，搜索并下载**你账号权限范围内**的曲目，直接得到带完整 ID3 标签的 MP3。

> 本工具仅供个人学习、研究，以及备份你依法有权获取的音频文件。使用前请阅读文末的[免责声明](#免责声明)。

## 功能

- **扫码登录** —— 全程不接触账号密码；登录凭据存入系统钥匙串（macOS Keychain / Windows Credential Manager），不落盘成明文
- **搜索下载** —— 搜索单曲，先试听再决定；下不了的曲目会**在点击之前**标明原因（无版权 / 需会员 / 需购买）并置灰
- **零转码** —— 固定请求 320k 档，服务端直接返回 mp3，落盘即完成。不需要 FFmpeg，安装包因此保持在 10MB 量级
- **完整 ID3** —— 自动写入标题、艺术家、专辑与封面，导入 Apple Music / Plex / Navidrome 不会显示「未知专辑」
- **断点续传** —— 下载进度存在本地 SQLite，关闭窗口即暂停，下次打开可继续
- **去重** —— 按曲目 ID 判定是否已下载，并会校验文件确实还在磁盘上
- **NCM 兼容** —— 可解密你手头已有的历史 `.ncm` 文件

## 使用

下载对应平台的安装包，打开后扫码登录，搜索 → 试听 → 下载。产物默认输出到 `~/Music/网易云下载`。

### 关于安装包未签名

分发包**没有代码签名**（需要付费的 Apple Developer / Windows 代码签名证书）：

- **Windows**：首次运行会出现 SmartScreen 提示，点「更多信息」→「仍要运行」
- **macOS**：首次打开可能提示「已损坏」或「无法验证开发者」，需在「系统设置 → 隐私与安全性」中放行

## 下载速度是刻意放慢的

下载**串行执行**，每首之间插入 0.9–2.6 秒随机间隔。上千首曲目可能需要数小时。

这不是性能缺陷，而是有意的取舍：高频调用接口会触发服务端风控，轻则接口临时失败，重则**账号受限**——而这用的是你日常听歌的真实账号，代价不止于本工具。节流参数在 `app/src-tauri/src/downloader.rs` 的 `Throttle` 中，可自行调整。

## 从源码构建

需要 [Node.js 20+](https://nodejs.org)、[Rust](https://rustup.rs) 与各平台的 Tauri 系统依赖（见 [Tauri 官方前置条件](https://tauri.app/start/prerequisites/)）。

```bash
cd app
npm install
npm run tauri dev     # 开发模式
npm run tauri build   # 构建安装包
```

Tauri 不支持从 macOS 交叉编译到 Windows。Windows 版本由 GitHub Actions 在 Windows runner 上原生构建，见 [.github/workflows/build.yml](.github/workflows/build.yml)：在仓库的 Actions 页手动触发即可下载产物，或推送 `v*` 标签生成 Release 草稿。

## 项目结构

```text
app/          Tauri + React 桌面应用
  src/          前端（登录 / 搜索 / 下载队列 / 曲库）
  src-tauri/    Rust 后端（请求加密、下载器、SQLite、钥匙串）
docs/         设计文档：9 份 ADR 与术语表
legacy/       早期的 Python 命令行脚本，保留作为 NCM 解密的回归基准
```
